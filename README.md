## 💙 About Halati

**Halati (حالتي)** is an Arabic-first health tracking application built
with Flutter. It helps users record symptoms, organize their health
history, track recurring patterns, manage follow-up appointments, and
generate structured health reports.

The project combines **Flutter**, **Supabase**, **Google Gemini**,
**REST API integration**, **PDF generation**, and **local
notifications** in one complete application.

> **Medical Disclaimer:** Halati organizes and summarizes user-provided
> information. It is not a diagnostic system and does not replace
> professional medical advice.

# ✨ Key Features

-   🩺 **Symptom Tracking** --- record symptoms, severity, location,
    recurrence, medications, date/time, and notes.
-   📚 **Health History** --- review, search, and filter previously
    recorded symptoms.
-   📊 **Health Analytics** --- calculate symptom types, average
    severity, recurring cases, and frequency.
-   🤖 **AI-Powered Summary** --- generate concise Arabic summaries
    using Google Gemini.
-   📄 **PDF Reports** --- export structured Arabic health reports for a
    selected date range.
-   📅 **Appointment Tracking** --- save doctor, clinic, appointment
    date, and notes.
-   🔔 **Daily Notifications** --- local reminders encourage users to
    keep their health log updated.
-   🔐 **Authentication** --- sign up, login, password recovery, and
    account sessions through Supabase.
-   👤 **Guest Mode** --- visitors can explore public areas while
    account-specific features remain protected.
-   🇸🇦 **Arabic RTL Interface** --- Arabic-first responsive design with
    consistent custom typography.

# 🧠 How the Smart Report Works

``` text
User Health Records
        ↓
Supabase Database
        ↓
Select Report Date Range
        ↓
Retrieve & Analyze Records
        ↓
Calculate Health Statistics
        ↓
Prepare Structured Data
        ↓
Google Gemini API
        ↓
Arabic AI Summary
        ↓
Generate PDF Health Report
```

The AI feature is intentionally used for **summarization, not
diagnosis**. It summarizes the information recorded by the user without
claiming a medical condition or replacing a healthcare professional.

# ⚙️ Getting Started

``` bash
git clone <YOUR_REPOSITORY_URL>
cd final_project
flutter pub get
```

Create a `.env` file using `.env_example`:

``` env
my_url=YOUR_SUPABASE_URL
my_publishableKey=YOUR_SUPABASE_PUBLISHABLE_KEY
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

Run on Chrome:

``` bash
flutter run -d chrome
```

Or run on an Android emulator/device:

``` bash
flutter run
```

> Never commit real API keys or your real `.env` file to a public
> repository.

# 🔒 Security & Privacy

Halati uses authenticated user sessions and user-specific database
records. Supabase Row Level Security should be configured so users can
access only their own records.

For production, secret AI credentials should be stored on a secure
backend or server function rather than inside a distributed Flutter
client.
